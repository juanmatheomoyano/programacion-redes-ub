Fondo fijo (background-attachment: fixed)

El padding separa el texto del borde. Con box-sizing:border-box el padding se resta del ancho declarado, por lo que la caja mide exactamente el width indicado.

Con background-attachment:fixed la imagen de fondo queda anclada al viewport: al hacer scroll dentro del div el texto se mueve pero el fondo permanece quieto.
